# Support

This is a community-maintained starter template.

Before asking for help:

1. Read the root README and the README for the affected workspace.
2. Search existing GitHub issues.
3. Reproduce the problem after `bun install --frozen-lockfile`.
4. Run `bun run check` and include the relevant, redacted output.

Use a
[bug report](https://github.com/npjonath/starter-turborepo-next-nest/issues/new?template=bug_report.yml)
for reproducible defects in the template. Use a
[feature request](https://github.com/npjonath/starter-turborepo-next-nest/issues/new?template=feature_request.yml)
for proposed improvements.

Questions about an upstream tool are usually best directed to that project's
documentation or support channels. This project does not provide guaranteed
response times or private implementation support.

Security concerns must follow [SECURITY.md](SECURITY.md).
