# Governance

`starter-turborepo-next-nest` is a maintainer-led community project.

## Roles

- **Contributors** improve the project through issues, documentation, code,
  tests, reviews, and other constructive participation.
- **Maintainers** triage work, review and merge changes, manage releases,
  enforce community standards, and coordinate security responses.

The current repository owner is the initial maintainer. Additional maintainers
may be invited after sustained, constructive contributions and demonstrated
care for the project's technical direction and community.

## Decisions

Routine decisions are made through issues and pull-request review. Significant
changes to architecture, supported runtimes, public APIs, or governance should
begin with an issue so the community can discuss tradeoffs before
implementation.

Maintainers seek practical consensus. When consensus cannot be reached, the
maintainers make the final decision based on security, accessibility,
maintainability, compatibility, and the project's scope.

## Releases and security

Maintainers decide when changes are released and may revert or patch changes
that create regressions. Security reports are handled privately according to
[SECURITY.md](SECURITY.md).

This governance model may evolve as the community grows. Material changes will
be documented in the repository.
